# Security Policy

Budget Dashboard handles research budget workflows, but public issues and pull requests must not contain real budget data, personal information, credentials, unpublished vulnerability details, or other confidential material.

## Reporting Data Safety or Security Concerns

Use the "Data safety or security consultation" issue template when the concern can be described safely in public.

Before posting:

- Remove real budget data, personal names, e-mail addresses, account names, file paths, and internal identifiers.
- Use synthetic sample data or the public demo seed when a reproduction is needed.
- Describe the affected workflow, expected risk, and sanitized reproduction steps.
- Do not attach workbooks, databases, screenshots, logs, or exports that contain confidential information.

This repository does not currently publish a private disclosure channel. If a concern cannot be described safely in public, open a minimal sanitized issue asking the maintainer to arrange a safer contact method, without including the sensitive details.

## Supported Versions

This repository is maintained from the `main` branch. Security and data-safety fixes are handled on the current public codebase.
